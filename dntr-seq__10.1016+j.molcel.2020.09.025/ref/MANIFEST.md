# Sources

Fetch using the standard source tool:

```sh
python3 tools/get_sources.py --slugs dntr-seq__10.1016+j.molcel.2020.09.025
```

Originals and extracted text remain in the external source store. The main research note and catalogue/source_reviews/dntr-seq__10.1016+j.molcel.2020.09.025.json record source identity, inspected scope and deferrals. Superseded preprints are excluded from active chemistry.
