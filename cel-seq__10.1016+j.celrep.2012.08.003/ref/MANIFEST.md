# Source manifest

- Defining article: Hashimshony T, Wagner F, Sher N, Yanai I. "CEL-Seq: single-cell RNA-Seq by multiplexed linear amplification." Cell Reports 2 (2012) 666–673. https://doi.org/10.1016/j.celrep.2012.08.003 (PMID 22939981; open access, CC BY-NC-ND 3.0). `tools/get_sources.py` leaves the article as a `(manual)` row. The publisher's supplement CDN serves the OA files directly: `https://ars.els-cdn.com/content/image/1-s2.0-S2211124712002288-mmc5.pdf` (article plus Supplemental Information) and `https://ars.els-cdn.com/content/image/1-s2.0-S2211124712002288-mmc4.pdf` (detailed CEL-Seq Protocol). Save them as `j.celrep.2012.08.003_mmc5.pdf` and `j.celrep.2012.08.003_mmc4.pdf` in `$CHEM_DATA/sources/cel-seq__10.1016+j.celrep.2012.08.003/`, then run `python3 tools/get_sources.py --slugs cel-seq__10.1016+j.celrep.2012.08.003 --revalidate` and `python3 tools/doctext.py` on the directory.
- Supporting primer design: CEL-Seq2 (Genome Biology 2016, https://doi.org/10.1186/s13059-016-0938-8) Additional file 5, Table S2; fetched into the CEL-Seq2 source directory with `python3 tools/get_sources.py --slugs cel-seq2__10.1186+s13059-016-0938-8`.
- Files and extracted text belong in `$CHEM_DATA/sources/`, not this directory.
