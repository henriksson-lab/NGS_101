# HiCAR references

No third-party source files are committed here. Re-obtain them with:

```sh
python3 tools/get_sources.py --slugs hicar__10.1016+j.molcel.2022.01.023
```

Primary sources:

- Wei et al., *Molecular Cell* (2022), doi:10.1016/j.molcel.2022.01.023,
  PMCID: PMC8934281 — defining CviQI/NlaIII HiCAR protocol and supplementary oligo table.
- Lu et al., *Current Protocols* (2023), doi:10.1002/cpz1.899,
  PMCID: PMC10575683 — authors’ expanded protocol and ordering table; this later version
  uses MseI for the first digest and is not substituted into the defining construct.
