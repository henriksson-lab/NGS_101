# TOPO TA cloning sources

Run `python3 tools/get_sources.py --slugs topo-ta-cloning`. Source identity, retrieval results and originals live in `/husky/henriksson/NGS101_papers/sources/topo-ta-cloning/MANIFEST.tsv`.

Primary source: https://assets.thermofisher.com/TFS-Assets/LSG/manuals/topota_man.pdf.

The official cached `topota_man.pdf` prints MAN0000047 RevisionA.0; its revision is checked by the local suite. An unversioned URL cannot substitute a different returned revision.
