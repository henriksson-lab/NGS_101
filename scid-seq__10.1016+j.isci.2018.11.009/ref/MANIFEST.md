# Sources

Fetch using the standard source tool:

```sh
python3 tools/get_sources.py --slugs scid-seq__10.1016+j.isci.2018.11.009
```

Originals and extracted text remain in the external source store. The main research note and catalogue/source_reviews/scid-seq__10.1016+j.isci.2018.11.009.json record source identity, inspected scope and deferrals. Superseded preprints are excluded from active chemistry.
