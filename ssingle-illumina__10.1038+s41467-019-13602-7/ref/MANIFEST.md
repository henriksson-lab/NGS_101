# Source retrieval

Run `python3 tools/get_sources.py --slugs ssingle-illumina__10.1038+s41467-019-13602-7`. Canonical originals and extracted text stay in `/husky/henriksson/NGS101_papers/sources/ssingle-illumina__10.1038+s41467-019-13602-7/`. `MANIFEST.tsv` records exact URLs, identities and failures.

Only sections listed in the source review and protocol note were read. No third-party original or text twin is checked in.
