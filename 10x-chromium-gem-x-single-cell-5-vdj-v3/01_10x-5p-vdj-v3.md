# 10x Chromium GEM-X Single Cell 5' V(D)J v3 — source note

The combined source audit and v2 primer-pool transcription are retained in the
[10x 5' V(D)J research note](../10x-chromium-single-cell-5-vdj/01_chromium-5-vdj.md).

**Primary source:** 10x Genomics, *Chromium GEM-X Single Cell 5' Reagent Kits v3 with
Cell Surface Protein User Guide*, **CG000734 Rev A**. It prints the v3 gel-bead primer,
complete V(D)J library and sequencing layout. The v3 guide specifies the same v2-labelled
V(D)J amplification kits for constant-region enrichment.

## Bounded source pass 2026-10-17 (round breadth-first-06)

Read CG000734 Rev A (scg-mirrored vendor PDF in the `10x-chromium-single-cell-5-vdj`
bundle; this slug's own bundle is empty): kit tables pp.8–9, assay overview pp.17–20
(text lines 1040–1130 and the rendered figures), sequencing pp.97–98 (lines 5885–5985)
and Appendix pp.111–113 (lines 6520–6573 plus rendered p.113).

- 🟢 Appendix p.113 *Additional Sequences* is a single image (no extracted text, zero
  scraper hits). It prints the universal forward primer
  `5'-GATCTACACTCTTTCCCTACACGACGC-3'` and every Human/Mouse T/B Mix 1 v2 outer and
  Mix 2 v2 inner reverse primer. All 46 members were compared with CG000331 Rev E
  pp.73–74 text and match. Earlier review passes said the v3 appendix omitted them;
  the v3 guide itself is therefore the primary source for the enrichment pools.
- 🟢 Kit tables pp.8–9: **Poly-dT RT Primer B PN-2001110** (v2 uses Poly-dT RT
  Primer PN-2000007) and **cDNA Primers PN-2000089** (same PN as v2).
- 🟡 CG000734 prints no RT-primer or cDNA-primer sequence in the inspected appendix.
  The model draws cDNA Primers from the PN-2000089 sequences printed in CG000331
  Rev E p.72 (same part number) and draws Primer B with the v2 PN-2000007 sequence as
  an **inferred** region; whether Primer B differs in sequence is open.
- 🟡 The TT i5/i7 primer 3′ ends are derived from the p.111 Sample Index PCR product;
  the guide prints the product, not the primers.
- 🟢 Sequencing p.98: Read 1 28, i7 10, i5 10, Read 2 90 cycles (model matches).
- 🟡 Read 2 adaptor: Step 4.2 (p.74) adds it in Ligation Mix PN-2001109 with DNA
  Ligase; the inspected kit tables, Step 4.2 and Appendix pp.111–113 print no adaptor
  oligo (v2 lists separate Adaptor Oligos PN-2000094). The model draws the CG000331
  Rev E Step 4.2 (p.74) half adaptor, 12-bp stem and 3′-T end, as an **inferred**
  ligation-ready state; the 3′-T end follows from the Step 4.1 A-tailing.

Open: Primer B sequence; Ligation Mix PN-2001109 adaptor structure; silane/SPRIselect cleanups and the cDNA size split are not
drawn as graph steps; Dual Index Kit TT Set A primer original not inspected.
