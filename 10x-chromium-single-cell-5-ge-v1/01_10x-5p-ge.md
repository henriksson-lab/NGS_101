## 1. What it is

Droplet (GEM) single-cell RNA-seq that reads the **5' end** of transcripts. Inside each
GEM a gel bead releases millions of copies of one **barcoded template-switching oligo
(TSO)**; the master mix supplies a **universal poly(dT) RT primer**. RT starts at the
poly(A) tail and, on reaching the 5' cap end of the mRNA, switches onto the bead TSO, so
the **cell barcode and UMI end up at the 5' end of the cDNA**. 🟢 (CG000109 p. 1;
CG000733 "Step 1")

Compared with 10x 3' GEX the roles of the two RT oligos are swapped: in 3' GEX the bead
carries the barcoded oligo-dT and a universal TSO is in the mix; here the bead carries the
barcoded TSO and the oligo-dT is universal. 🟡 (upstream; the 3' kit is not in these
sources)

| | Idea | Where else |
|---|---|---|
| 1 | Cell barcode + UMI on the **TSO**, read from the 5' end | STRT-seq / STRT-seq-2i, SMART-seq3 (UMI in TSO, no cell barcode) |
| 2 | One amplified cDNA pool feeds **several libraries** (5' GEX, TCR, BCR) | V(D)J enrichment by nested PCR with C-region primers from the same cDNA |
| 3 | Library by **enzymatic fragmentation + end repair/A-tail + ligation** of a short Read-2 adapter, then index PCR | 10x 3' GEX (same back end) |

Concepts: [template switching](../ref/concepts/template-switching.md),
[reverse transcription](../ref/concepts/reverse-transcription.md).

## 2. Oligos

### 2a. v1 (CG000109 Table 2B, 5' Gene Expression) — 🟢

Written exactly as the Technical Note gives them (hyphens are the note's segment
separators; `rG` = ribo-G; N16 = 10x Barcode, N10 = UMI):

```
Gel Bead Oligo Primer (TSO), PN-220112
  5'-CTACACGACGCTCTTCCGATCT-NNNNNNNNNNNNNNNN-NNNNNNNNNN-TTTCTTATATrGrGrG-3'

Poly-dT RT Primer, PN-2000007
  5'AAGCAGTGGTATCAACGCAGAGTAC-TTTTTTTTTTTTTTTTTTTTTTTTTTTTTTVN-3'

cDNA Primer Mix, PN-220106
  Forward primer (Partial Read 1):    5'-CTACACGACGCTCTTCCGATCT-3'
  Reverse primer (Non-Poly(dT)):      5'- AAGCAGTGGTATCAACGCAG-3'        (Table 2B)
                                      5'- AAGCAGTGGTATCAACGCAGAG-3'      (Table 2A, same PN)

Adaptor (Read 2), PN-220026 — double-stranded
  5'-GATCGGAAGAGCACACGTCTGAACTCCAGTCAC-3'
  5'-GCTCTTCCGATCT-3'   (the partner strand, written 5'->3'; upstream draws it 3'->5')

Sample Index PCR Primer, PN-220111 and PN-220103
  Forward (P5 – Partial Read 1):            5'-AATGATACGGCGACCACCGA-GATCTACACTCTTTCCCTACACGACGCTC-3'
  Reverse (P7 – Sample Index – Partial R2): 5'-CAAGCAGAAGACGGCATACGAGAT-NNNNNNNN-GTGACTGGAGTTCAGACGTGT-3'
```

Not in the 10x sources but listed by upstream 🟡: TruSeq Read 1 primer
`ACACTCTTTCCCTACACGACGCTCTTCCGATCT`, TruSeq Read 2 primer
`GTGACTGGAGTTCAGACGTGTGCTCTTCCGATCT`, and the Sample index sequencing primer
`GATCGGAAGAGCACACGTCTGAACTCCAGTCAC` (identical to the Read-2 adaptor top strand). The
sequencing-primer **sites** are in the 10x library drawings (🟢), the primers themselves
are Illumina's.

Modifications not stated anywhere 🔴: whether the adaptor top strand carries a 5'
phosphate (it must, to ligate), whether the poly(dT) primer or the bead oligo is 5'
blocked, and how the bead oligo is attached (`|--` in upstream's drawing).

### 2b. v3 / GEM-X (CG000733, "Oligonucleotide Sequences") — 🟢

```
Gel Bead Primers
```

The v3 guide gives no other oligo sequence in text: the RT primer is "Poly-dT RT Primer B",

v1 is 🟡 (consistent with the final v3 library in §4, which contains the same handles).

### 2c. TCR/BCR enrichment primers

CG000109 Tables 1 and 2A also list the human T- and B-cell outer/inner constant-region
primers (Mix 1 / Mix 2) for the V(D)J libraries. They are not part of 5' GEX and are not
reproduced here.

### How the oligos interlock — 🟡 (computed)

- **Bead TSO 5' part = `illumina.TRUSEQ_READ1[11:]`** — the last 22 nt of TruSeq Read 1
  ("Partial Read 1"). The first 11 nt (`ACACTCTTTCC`) are added later by the P5 index
  primer.
- **Bead TSO 3' part = `TTTCTTATAT` + `rt.TSO_G_TAIL`** — 13 nt, the "13 nt Switch
  Oligo" of CG000109 🟢; `rGrGrG` pairs with the untemplated `CCC`. In the library this
  reads `TTTCTTATATGGG` immediately after the UMI, so **Read 1 cycle 27 onwards (v1/v2) or
  29 onwards (v3) is constant sequence**, then the transcript's 5' end.
- **Poly(dT) RT primer = `rt.SMART_HANDLE` + `AC` + T30 + `VN`** = 57 nt, i.e.
  `rt.oligo_dt(30, "VN", handle=rt.SMART_HANDLE + "AC")` — the SMART/ISPCR handle on an
  anchored oligo-dT.
- **cDNA reverse primer** is a prefix of `rt.SMART_HANDLE`: 20 nt in Table 2B / upstream,
  22 nt in Table 2A. Both anneal to the same place; the cDNA forward primer is the bead's
  22-nt Partial Read 1 itself. So full-length cDNA is flanked by **Partial Read 1** (5'
  end of the transcript) and the **SMART handle** (3' end).
- **Read-2 adaptor top strand = `illumina.INDEX1_PRIMER`** = `revcomp(TRUSEQ_READ2)[1:]`
  (33 nt). Its 5' 12 nt are `illumina.STEM` (`GATCGGAAGAGC`).
- **Read-2 adaptor bottom strand**, 5'→3', is `GCTCTTCCGATCT` (13 nt): the 12 nt that
  pair with `STEM` plus a **3' T overhang** for TA ligation to the A-tailed fragments. The
  same 13 nt are also the 3' end of both TruSeq Read 1 and Read 2.
- **P5 index primer (PN-220111)** = `illumina.P5` + `TRUSEQ_READ1[4:24]` — 49 nt.
  `P5` ends `…ACAC` and Read 1 begins `ACAC`, so they **share 4 nt**; the primer's last 13
  nt (`CTACACGACGCTC`) overlap the 5' end of the bead's Partial Read 1, which is where it
  anneals. The full v1 junction `P5 + TRUSEQ_READ1[4:]` is identical to
  `illumina.NEBNEXT_UNIVERSAL_PRIMER` (58 nt).
- **P7 index primer (PN-220103)** = `illumina.P7` + 8-nt index + `TRUSEQ_READ2[:21]`
  (`GTGACTGGAGTTCAGACGTGT`), which is the reverse complement of the adaptor top strand's
  last 21 nt — so it primes off the ligated adaptor.
- **Index orientation** 🟡: the primer carries the index as `P7–N8–R2`; in the library
  top strand it reads `…R2'–N8'–P7'`, i.e. the i7 read (primed by `INDEX1_PRIMER`) reads
  the **reverse complement** of what is written in the primer. The 8-nt sequences are
  not in the sources. 🔴

## 3. Step by step

v1 reaction structure from CG000109 (which gives products, not conditions); conditions
are 🟢 from the **v3** guide CG000733 unless stated. v1/v2 conditions were not available.

1. **GEM generation** (Chromium X/iX, "GEM-X 5P" program, ~6 min). Cell, gel bead and
   master mix (RT Reagent E, RT Enzyme E, Poly-dT RT Primer B, Reducing Agent B) in one
   droplet; the bead dissolves, the cell lyses. Cell recovery targets 500–10,000 or
   10,000–20,000 cells per channel depending on load. 🟢
2. **GEM-RT**: 48 °C 45 min, 85 °C 5 min, 4 °C. 🟢
   - Poly(dT) RT primer anneals to the poly(A) tail; RT copies the mRNA.
   - At the mRNA 5' end the RT adds non-templated C's, the bead TSO's `rGrGrG` pairs
     with them, and RT continues onto the TSO. First strand (as CG000109 draws it,
     3'→5' as written in the source):
     `3'-Partial R1'-CB'-UMI'-AAAGAATATACCC-cDNA-NV-T30-CATGAGACGCAACTATGGTGACGAA-5'`, i.e. the
     poly(dT) RT primer itself (handle + `AC` + T30 + `VN`, written backwards) at the 5' end. 🟢
     Mechanism: [template switching](../ref/concepts/template-switching.md). The enzyme
     is not named ("RT Enzyme E"); upstream says MMLV. 🔴/🟡
3. **Post GEM-RT cleanup**: Recovery Agent breaks the emulsion; Dynabeads MyOne SILANE in
   Cleanup Buffer (10 min RT) purify the first-strand cDNA. 🟢
4. **cDNA amplification**: Amp Mix + cDNA Primers, 98 °C 45 s; n × (98 °C 20 s, 63 °C
   30 s, 72 °C 1 min); 72 °C 1 min. Total cycles by targeted recovery: <500 → 17,
   501–2,000 → 15, 2,001–6,000 → 13, >6,000 → 12. 0.6× SPRIselect, elute 40 µl. 🟢
   Product: `Partial R1 · CB · UMI · TTTCTTATATGGG · cDNA · (dT) · handle'` (double
   stranded). 🟢 (CG000109 Table 2B)
5. *(Optional, separate libraries)* TCR/BCR enrichment by two nested PCRs from the same
   cDNA — not 5' GEX.
6. **Fragmentation, End Repair & A-tailing**: only 10 µl (25 %) of the cDNA; 32 °C 5 min,
   65 °C 30 min (block pre-cooled to 4 °C). Double-sided SPRIselect 0.6× / 0.8×. 🟢
7. **Adaptor ligation**: Ligation Mix + DNA Ligase, 20 °C 15 min; 0.8× SPRIselect. 🟢
   The T-overhang Read-2 adaptor ligates to A-tailed fragment ends. 🟡
8. **Sample Index PCR**: Library Amp Mix + one well of Dual Index TT Set A (v3; in v1 the
   P5 primer PN-220111 + P7/i7 primer PN-220103 🟢); 98 °C 45 s; n × (98 °C 20 s, 54 °C
   30 s, 72 °C 20 s); 72 °C 1 min. Cycles by cDNA input: 0.25–50 ng → 14–16, 50–250 → 12–14,
   250–600 → 10–12, 600–1,100 → 8–10, 1,100–1,500 → 6–8, >1,500 → 5. Double-sided SPRIselect 0.6× / 0.8×. 🟢
9. **QC**: Bioanalyzer High Sensitivity, 200–2,000 bp region; KAPA qPCR. 🟢

**Which fragments become library** — 🟡 (inferred; not stated by 10x). Only fragments that
kept the bead end carry Partial Read 1, so only they can be primed by the P5 primer;
internal fragments and those carrying the poly(dT)/handle end have no P5-side site and
do not amplify exponentially. Upstream explains the latter by assuming the oligo-dT and
TSO 5' ends are blocked, and speculates that internal fragments with adaptor at both ends
are suppressed — both labelled as assumptions there 🟡/🔴. The bead end is also A-tailed
and can take an adaptor; what happens to that end is not described. 🔴

## 4. Final libraries

Segment lists, 5'→3', top strand (the strand that begins with P5).

**v1 (and v2 per upstream)** — 🟢 CG000109 Table 2B "Sample Index PCR Product":

```
5'- P5 (29) · TruSeq Read 1[4:] (29; shares ACAC with P5) · 10x Barcode N16 · UMI N10
    · TTTCTTATATGGG · cDNA insert (5' end of transcript)
    · A · INDEX1_PRIMER (33) · i7 N8 · P7' (24) -3'
```

Fixed length excluding insert: 163 nt 🟡 (computed).

**v3 / GEM-X** — 🟢 CG000733 "Gene Expression Library – Sample Index PCR Product":

```
5'- P5 (29) · i5 N10 · TruSeq Read 1 (33, complete) · 10x Barcode N16 · UMI N12
    · TTTCTTATATGGG · cDNA insert
    · A · INDEX1_PRIMER (33) · i7 N10 · P7' (24) -3'
```

Fixed length excluding insert: 181 nt 🟡 (computed). Note the P5 side: in v1 P5 runs
straight into Read 1 (`…GATCTACACTCTTTCCC…`, 4-nt overlap); in v3 a 10-nt i5 sits
between P5 and a complete Read 1, which is the standard Illumina dual-index arrangement.

## 5. Read layout / sequencing

| | v1 / v2 | v3 (GEM-X) |
|---|---|---|
| Read 1 (TruSeq R1 primer) | 26 cycles: CB 16 + UMI 10 🟡 (upstream; 10x figure not extractable) | **28** 🟢 (CB 16 + UMI 12) |
| i7 index | 8 nt index (N8, CG000109 Table 2B) 🟢; cycle count not extractable | **10** 🟢 |
| i5 index | none for v1 🟢 (CG000109 p. 2: sample index read as i7 only); v2 🟡 (upstream) | **10** 🟢 |
| Read 2 (TruSeq R2 primer) | 98 🟡 (upstream, not tied to a version) | **90** 🟢 |

- Read 2 starts at a **random internal** position of the insert (enzymatic fragmentation)
  🟢 (CG000109 p. 2); it reads toward the transcript 5' end 🟡 (follows from the
  adaptor being on the fragment's 3'-side end).
- Read 1 reads the barcode and UMI; continued past them it would read `TTTCTTATATGGG` then
  the transcript 5' end (the V(D)J libraries are read this way, CG000109 p. 2). 🟢/🟡
- v3 depth: ≥20,000 read pairs per cell for 5' GEX (≥5,000 for V(D)J); paired-end, dual
  indexing; MiSeq, NextSeq 500/550, NextSeq 1000/2000, HiSeq 2500 RR, HiSeq 3000/4000, NovaSeq 6000. 🟢
- Cell barcode whitelists (from upstream 🟡): v1/v2 `737K-august-2016.txt` (shared with
  3' v2); v3 `3M-5pgex-jan-2023.txt`.

## 8. How this note was made (tool evaluation)

`tools/get_sources.py` fetched only the upstream page (correct: no publication). The two
10x PDFs were downloaded by hand from the copies upstream links and converted with
`tools/doctext.py`. `tools/scrape_primers.py` found the poly(dT) primer, cDNA primers,
adaptor and index primers and recognised `rt.SMART_HANDLE`, `illumina.P5`,
`TRUSEQ_READ1/2`, `INDEX1_PRIMER`, `P7_RC`; it did **not** report the gel-bead TSO as one
oligo (split at the N16/N12 placeholders, so `TTTCTTATATrGrGrG` and its ribo-G
modification were never listed), and it glued the word "cDNA" onto sequences
(`…TTTCTTATATGGGcDNA`). `--find` cannot match a sequence containing an N placeholder
run, so barcoded/indexed oligos were checked segment by segment.
