## 1. What it is

A droplet method: cells and **barcoded gel beads** are co-encapsulated in a "Gel bead in
EMulsion" (GEM) on an 8-channel chip; the bead dissolves and releases its oligos, RT
happens inside each droplet, then the emulsion is broken and everything downstream is
bulk. 🟢 (paper, Results; user guide Step 2)

Each bead oligo carries 🟢 (paper; user guide): an Illumina **P7** and **Read 2** sequence,
a **14 bp barcode** drawn from ~750,000 designed sequences, a **10 bp randomer (UMI)**, and
an **anchored 30 bp oligo-dT**. Some early libraries had a **5 bp UMI** (14 libraries,
Supp. Table 1 — including the 68k fresh PBMCs). 🟢

| | New thing here | Where else it turns up |
|---|---|---|
| 1 | **Cell barcode read as the i7 index** (14 cycles), sample index as i5 — standard Illumina primers only, no custom read primers 🟢 | unique to v1; v2+ put the barcode in Read 1 |
| 2 | **Read 2 is only 10 nt**: it reads the UMI and nothing else; Read 1 (98 nt) is the cDNA 🟢 | inverted relative to Drop-seq / v2, where Read 1 is barcode + UMI |
| 3 | Bead-delivered oligo-dT + [template switching](../ref/concepts/template-switching.md) for full-length cDNA, then **shear + end-repair + A-tail + ligation** to put the P5 side on 🟢 | Drop-seq uses Nextera on cDNA; v2–v4 keep the ligation front end |

The RNA front end is ordinary oligo-dT [reverse transcription](../ref/concepts/reverse-transcription.md)
with a template switch; what is specific to v1 is where the barcodes sit in the reads.

## 2. Oligos

🟡 **All sequences below come only from the upstream scg_lib_structs page**, written as it
writes them (IDT-style `rG` = ribo-G). The upstream author states they are an educational
guess, checked against the v1 manual and real data. The primary sources name the
reagents but never print sequences. The `|--` marks the bead attachment as upstream draws it.

```
Beads-oligo-dT            |--5'- CAAGCAGAAGACGGCATACGAGAT[14-bp cell barcode]GTGACTGGAGTTCAGACGTGTGCTCTTCCGATCT[10-bp UMI](T)30VN -3'
Template Switching Oligo  5'- AAGCAGTGGTATCAACGCAGAGTACATrGrGrG -3'
ISPCR                     5'- AAGCAGTGGTATCAACGCAGAGTACAT -3'
Illumina P7 adapter       5'- CAAGCAGAAGACGGCATACGAGAT -3'
Truseq adapter, top       5'- TCTTTCCCTACACGACGCTCTTCCGATCT -3'
Truseq adapter, bottom    5'- GATCGGAAGAGC -3'            (upstream writes it 3'->5' as CGAGAAGGCTAG)
SI-PCR Primer             5'- AATGATACGGCGACCACCGAGATCTACAC[8-bp sample index]ACACTCTTTCCCTACACGACGCTCTTCCGATCT -3'
Truseq Read 1 primer      5'- ACACTCTTTCCCTACACGACGCTCTTCCGATCT -3'
Truseq Read 2 primer      5'- GTGACTGGAGTTCAGACGTGTGCTCTTCCGATCT -3'
Cell barcode seq. primer  5'- GATCGGAAGAGCACACGTCTGAACTCCAGTCAC -3'   (index 1)
Sample index seq. primer  5'- AGATCGGAAGAGCGTCGTGTAGGGAAAGAGTGT -3'   (index 2)
```

How these map onto the v1 kit's reagent names (user guide, kit contents 🟢 for the names;
mapping 🟡):

| Kit reagent (user guide) 🟢 | Upstream oligo 🟡 | Note |
|---|---|---|
| Single Cell 3′ Gel Beads | Beads-oligo-dT | composition agrees with paper and guide |
| **RT Primer** (lyophilized, 4 µl into the GEM master mix) | TSO | the guide never says what "RT Primer" is; the oligo-dT is on the bead, so the separately added oligo is presumably the TSO 🟡 |
| cDNA Primer Mix | ISPCR + P7 | paper: "primers complementary to the switch oligos and sequencing adapters" 🟢 — agrees in kind |
| R1 Adaptor Mix | Truseq adapter (T-overhang duplex) | |
| SI-PCR Primer + Single Cell 3′ Sample Index Plate | SI-PCR Primer + P7 | **naming disagreement:** in the kit the *SI-PCR Primer* is one common tube and the per-sample index comes from the plate (10 µl per well); upstream calls the *indexed* P5 oligo "SI-PCR Primer". Since the index is read as i5, the plate presumably holds the P5–index–R1 oligos and the common tube the P7 primer 🟡 |

### How they interlock — 🟡 (computed with `lib/`)

- Bead oligo = **`illumina.P7`** (24) + 14-nt barcode + **`illumina.TRUSEQ_READ2`** (34)
  + UMI (10) + T30 + VN → **114 nt** (109 nt with the early 5-nt UMI). P7 sits at the bead
  end, so the cDNA's 3′ end later carries the full P7 site without further addition.
- TSO = **`rt.SMART_HANDLE`** + `ACAT` + `rGrGrG`; ISPCR is the same 27-nt handle without the
  Gs, i.e. the TSO minus its 3′ ribo-Gs (`AAGCAGTGGTATCAACGCAGAGT` + `ACAT`). Not the 23-nt
  SMART-seq2 ISPCR, and not the Drop-seq TSO.
- Truseq adapter top strand = **`illumina.TRUSEQ_READ1[4:]`** (29 nt, lacks the 5′ `ACAC`),
  ending in the 3′-T overhang. Bottom strand (5′→3′) = `GATCGGAAGAGC` = **`illumina.STEM`**,
  which pairs with the top strand's `GCTCTTCCGATC` and leaves the T unpaired. This is the
  short "forked/stubby" Y-adapter form: only 12 bp of duplex.
- SI-PCR Primer = **`illumina.P5`** + 8-nt index + **`illumina.TRUSEQ_READ1`** (33). Its 3′
  29 nt are the adapter top strand, so it primes on the ligated adapter and extends it by
  `ACAC` + index + P5.
- Cell barcode sequencing primer = **`illumina.INDEX1_PRIMER`**, and reverse complement of
  the bead's Read 2 sequence = `A` + `INDEX1_PRIMER` — the standard TruSeq i7 read primer
  starts reading **right after** the Read 2 site, i.e. straight into the cell barcode.
- Sample index sequencing primer = **`illumina.INDEX2_PRIMER_RC`** = revcomp(`TRUSEQ_READ1`)
  — the standard i5 read primer, reads the 8-nt sample index.
- Barcode orientation: all **3,388** barcodes in Supplementary Data 2 occur **as written**
  in Cell Ranger's `737K-april-2014_rc.txt` (0 as reverse complement); the whitelist has
  **737,280** 14-nt entries (the paper's "~750,000" 🟢). The i7 read copies the top
  (cDNA-sense) strand, i.e. the reverse complement of the barcode as synthesised on the
  bead — consistent with the whitelist file's `_rc` name. 🟡

## 3. Step by step

Conditions 🟢 from the paper's methods unless marked *(guide)* = v1 user guide CG00026 Rev B.

1. **GEM generation.** Cells, master mix (RT Reagent Mix, RT Primer, RNase Inhibitor,
   Additive A, RT Enzyme) and gel beads are combined in oil on the chip; ~100,000 GEMs per
   channel per ~6-min run, at a ~80 % gel-bead fill rate *(paper)*. The bead dissolves and
   releases its oligos; cells lyse.
2. **GEM-RT**: 55 °C 2 h, 85 °C 5 min, 4 °C hold. The oligo-dT primes on the poly(A) tail;
   at the mRNA 5′ end MMLV-type RT adds untemplated C's and switches to the TSO 🟡
   (mechanism: [template switching](../ref/concepts/template-switching.md); the paper only
   says each cDNA "ends with a template switching oligo at the 3′ end"; the enzyme is not
   named 🔴). First strand, 5′→3′:
   `P7 · CB · R2 · UMI · T30VN · <cDNA, antisense> · CCC · TSO′` 🟡
3. **Break GEMs, clean up**: Recovery Agent *(guide)*, DynaBeads MyOne Silane, then 0.6× SPRIselect.
4. **cDNA PCR** (cDNA Primer Mix + Amplification Master Mix + cDNA Additive *(guide)*):
   98 °C 3 min; 14 × (98 °C 15 s, 67 °C 20 s, 72 °C 1 min); 72 °C 1 min. The guide scales
   cycles with targeted cell recovery: 14 (< 2,000 cells), 12 (2,000–6,000), 10 (> 6,000).
   0.6× SPRIselect. Product: `ISPCR handle · GGG · <cDNA> · polyA · UMI · R2′ · CB′ · P7′` 🟡
5. **Shear** to ~200 bp (Covaris M220). Double-sided SPRI size selection *(guide)*: 30 µl
   SPRI to 50 µl (keep supernatant), then +10 µl SPRI to 75 µl of it (keep beads).
6. **End repair and A-tailing** *(guide)*: 20 °C 30 min, 65 °C 30 min.
7. **Adapter ligation** of the R1 Adaptor Mix *(guide)*: 20 °C 15 min; two SPRI cleanups
   (88 µl to 110 µl, then 50 µl to 50 µl).
   Only 3′-end fragments (`… polyA · UMI · R2′ · CB′ · P7′`) carry P7; the 5′-end (TSO)
   and internal fragments have no P7 site and cannot form a P5…P7 molecule 🟡. Upstream
   additionally assumes the TSO/ISPCR and P7 primer 5′ ends are blocked so the adapter
   ligates only to the sheared end; nothing in the primary sources confirms this 🔴.
8. **Sample index PCR** *(guide)*: 60 µl mix (Amplification Master Mix + 2 µl SI-PCR
   Primer) + 30 µl ligated DNA + **10 µl Sample Index** from the plate; 98 °C 45 s;
   10 × (98 °C 20 s, 60 °C 30 s, 72 °C 20 s); 72 °C 1 min. Each sample index is a
   **mix of 4 different sequences** for base balance *(guide)*; the 4 sequences per set are
   not given 🔴. Two SPRI cleanups (100 µl to 100 µl, then 50 µl to 50 µl).
9. **QC / quantify**: Bioanalyzer *(guide)*, KAPA qPCR.

## 4. Final library — 🟡 (assembled from the upstream oligos; layout agrees with the paper and guide)

Top strand, 5′→3′:

```
5'- P5 · i5 (8, sample index) · TruSeq Read 1 (33) · <cDNA, sense, ~3' end> · B · (A)30 · UMI (10) · revcomp(TruSeq Read 2) (34) · revcomp(CB) (14) · revcomp(P7) (24) -3'
```

Agreements and disagreements with the primary sources:

- 🟢 **Agrees:** the guide's final-library figure, drawn P7→P5, is `P7 · 10x Barcode · Read 2 ·
  Randomer · cDNA · Read 1 · Sample Index · P5` — the same order as the line above read
  backwards.
- 🟢 **Agrees:** P7 + Read 2 come from the bead during GEM-RT; P5, Read 1 and the sample index
  are added by end repair, A-tailing, adapter ligation and PCR (guide; paper methods
  list the same four library steps).
- 🟡 **Simplification upstream:** one 8-nt i5 per library; the kit uses 4 base-balanced
  sequences per sample index.
- 🟡 Fixed flanks *(computed)*: 70 nt on the P5 side (29 + 8 + 33), 72 nt on the P7 side
  (34 + 14 + 24), plus UMI and ~30-nt poly(A).

## 5. Sequencing

🟢 Paper: NextSeq 500, 2 × 75 kit, loaded at 2.1 pM, **98 bp Read 1, 14 bp I7, 8 bp I5,
10 bp Read 2** (5 bp Read 2 for the 14 early libraries with 5-nt UMI). Supp. Table 1 also
lists libraries run on **HiSeq 2500 Rapid Run V2**, which the methods text does not mention.
🟢 Guide: same read lengths ("any other length will result in a failed run" for I7, I5 and
Read 2); validated on NextSeq 500 (V2, 150-cycle) and HiSeq 2500 Rapid Run (200-cycle);
**standard Illumina primers only, no custom primers**.

| Read | Primer 🟡 (upstream / computed) | Reads | Length 🟢 |
|---|---|---|---|
| Read 1 | `illumina.TRUSEQ_READ1` | cDNA, sense strand, from the sheared end towards the poly(A) | 98 |
| Index 1 (i7) | `illumina.INDEX1_PRIMER` | 14-nt cell barcode (as the whitelist writes it) | 14 |
| Index 2 (i5) | `illumina.INDEX2_PRIMER_RC` | 8-nt sample index | 8 |
| Read 2 | `illumina.TRUSEQ_READ2` | 10-nt UMI (then poly(T), not sequenced) | 10 |

## 6. Open questions

- 🔴 Every oligo sequence. The paper, its supplement and the v1 user guide give none;
  the upstream page reconstructs them from TruSeq parts and data. The TSO in particular
  (SMART handle + `ACAT` + `rGrGrG`) is the later v2 design assumed for v1.
- 🔴 What exactly "RT Primer" (the separately added oligo in the GEM master mix) is.
- 🔴 The four sequences of each Single Cell 3′ Sample Index set, and which strand/end the
  common "SI-PCR Primer" covers (upstream's naming conflicts with the kit's — §2).
- 🔴 Whether the ISPCR / P7 primers are 5′-blocked to keep the adapter off the
  non-sheared ends, as upstream assumes.
- 🔴 The RT enzyme, and the composition of the 5-nt-UMI bead oligo (shorter oligo, or
  same oligo read for only 5 cycles?).

## 7. How this note was made (tool evaluation)

`tools/get_sources.py` fetched the upstream page, the Europe PMC XML, and all supplements
(twice: from the EPMC zip and from Springer, identical md5). The saved PMC HTML page is a
reCAPTCHA interstitial, and `tools/doctext.py` made no text twin of the XML, so the full
text was converted by hand to `ncomms14049_PMC5241818.xml.txt`. The v1 user guide and the
barcode whitelist are linked from the upstream page but were not fetched; they were
downloaded by hand from the scg_lib_structs site. The supplementary tables are images in
the PDF, so Supp. Table 1 was read from a rendering. `tools/scrape_primers.py` found the
upstream oligos (with P5/P7/TruSeq parts recognised) and otherwise only ddPCR probes and
14-nt cell barcodes from the xlsx — correctly showing that no primary source holds
library oligo sequences.
