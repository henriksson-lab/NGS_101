# Source manifest

- Defining paper: doi:10.1093/nar/gkag652; source pointers are obtainable with `python3 tools/get_sources.py --doi 10.1093/nar/gkag652`.
- Original kit manual: [NEBNext Small RNA Library Prep Set for Illumina E7300/E7330, v9.0_07/25](https://www.neb.com/en/-/media/nebus/files/manuals/manuale7300_e7330_e7560_e7580.pdf). The paper's Supplementary Methods identify E7300S. The official manual is configured in `catalogue/extra_sources.tsv` for `tools/get_sources.py` and contains the adapter/primer sequences on page 16.
- No third-party source files are committed.
