# Sources

Retrieve published originals and manifests into the external source store:

```sh
python3 tools/get_sources.py --slugs dab-seq__10.1038+s41467-021-21810-3
```

The main note and catalogue/source_reviews/dab-seq__10.1038+s41467-021-21810-3.json record exact inspected sections, revision identities and deferred sources. Downloads and extracted source text are not stored in this checkout. Superseded preprints are excluded from active chemistry.
