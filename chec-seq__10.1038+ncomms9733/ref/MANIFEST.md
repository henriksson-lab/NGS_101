# Sources

No third-party source files are committed here. Re-obtain the defining article, the
authors' detailed protocol and the cited low-input library procedure with:

```sh
python3 tools/get_sources.py --slugs chec-seq__10.1038+ncomms9733
```

The registered sources include PMC4618392, the later detailed procedure
PMC5608238 (also DOI 10.3791/55836), separate Orsi procedure PMC4410783,
directly cited library predecessors PMC3215028 and PMC3889552, original
corrigenda PMC4703876 and PMC5465364, and GSE67453 family metadata. Check
`MANIFEST.tsv` for failed routes; a failed Cloud route does not establish that
another original full-text route is unavailable. Downloaded files and extracted
text belong under `$CHEM_DATA/sources/`, not in this repository.
