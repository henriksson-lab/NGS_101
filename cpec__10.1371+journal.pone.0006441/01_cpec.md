## Molecular model

🟢 The linear duplex insert and backbone have terminal overlaps. After denaturation and annealing they extend using each other as templates; the source describes one nick per strand, followed by transformation. No additional PCR primers are added to this extension reaction.

🟡 The model uses neutral backbone and insert roles with unassigned sequence, length and nick coordinates. It distinguishes the unsealed duplex intermediate from an intended host-recovered construct. Host repair and selection remain an explicit boundary. This is a construct endpoint, with no assigned sample indexes or sequencing readout.
