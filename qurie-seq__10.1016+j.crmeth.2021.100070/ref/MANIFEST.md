# Sources

Retrieve published originals and manifests into the external source store:

```sh
python3 tools/get_sources.py --slugs qurie-seq__10.1016+j.crmeth.2021.100070
```

The main note and catalogue/source_reviews/qurie-seq__10.1016+j.crmeth.2021.100070.json record exact inspected sections, revision identities and deferred sources. Downloads and extracted source text are not stored in this checkout. Superseded preprints are excluded from active chemistry.
