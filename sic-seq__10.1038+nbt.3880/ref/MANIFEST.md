# Sources

Fetch using the standard source tool:

```sh
python3 tools/get_sources.py --slugs sic-seq__10.1038+nbt.3880
```

Originals and extracted text remain in the external source store. The main research note and catalogue/source_reviews/sic-seq__10.1038+nbt.3880.json record source identity, inspected scope and deferrals. Superseded preprints are excluded from active chemistry.
