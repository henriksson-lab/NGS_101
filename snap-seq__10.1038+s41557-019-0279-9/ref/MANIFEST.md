# Source retrieval

Run `python3 tools/get_sources.py --slugs snap-seq__10.1038+s41557-019-0279-9`. Canonical originals and extracted text stay in `/husky/henriksson/NGS101_papers/sources/snap-seq__10.1038+s41557-019-0279-9/`. `MANIFEST.tsv` records exact URLs, identities and failures.

Only sections listed in the source review and protocol note were read. No third-party original or text twin is checked in.
