# Reference manifest

Third-party source material is not committed. Re-obtain it with:

```sh
python3 tools/get_sources.py --doi 10.1038/s41556-024-01449-0
```

The defining article is Sun et al., *Nature Cell Biology* (2024),
doi:10.1038/s41556-024-01449-0. Its public Supplementary Tables XLSX contains
Supplementary Table 1 (SPATAC primers). The authors' processing code and molecular
workflow are at <https://github.com/Lan-lab/SPATAC-seq>; GEO GSE215901 describes the
library design and deposited reads.
