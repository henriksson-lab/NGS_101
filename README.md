# NGS 101

Base-by-base schematics of sequencing-library chemistries, showing how each protocol
builds a molecular construct and how the completed library is read.

[Explore the protocols](https://henriksson-lab.github.io/NGS_101/) ·
[About this project](https://henriksson-lab.github.io/NGS_101/about.html)

The **Annotate sequence** tab finds known primer and adapter parts in pasted DNA,
links to protocols sharing those parts, and aligns selected matches with query context.
The **Sample-sheet indexes** tab extracts Illumina indexes from lists of primer pairs.
Both tools run locally in your browser.

The **Anneal primers** tab explores exact linear and padlock pairing arrangements
and exports SVG diagrams using the same Python model as the protocol pages.
