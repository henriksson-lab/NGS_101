# Human NET-seq originals

Run `python3 tools/get_sources.py --slugs human-net-seq__10.1016+j.cell.2015.03.010` to obtain registered originals and text twins under `$CHEM_DATA/sources/`. The manifest records exact URLs, hashes and actual route failures. Run the full bundle oligo scraper before reading.

Registered sources include the defining Cell2015 original and separate author-hosted extended-methods PDF, the exact inherited Churchman2012 full protocol linked from the official author publication page, Churchman2011 originals and Ingolia2012 depletion methods. The detailed human2016 protocol is PMC5326677 / DOI10.1038/nprot.2016.047; it is a successor, not a replacement for2015.

The separate Cell TableS1 original is PMC SD6, `NIHMS680477-supplement-6.pdf`,65.9KB. The author PDF does not contain this table; current direct PMC routes are gated and the TDM Cloud record lacks attachments. This access barrier does not establish scientific absence. See the source-review JSON for exact source/version reading bounds and pending originals. No third-party materials are committed.
