# About NGS 101

NGS 101 is a collection of base-by-base schematics for sequencing-library chemistries.
Each protocol page aims to show how the molecular construct changes and how the completed
library is read.

## How to cite

Until the repository has a versioned archival DOI, please cite the repository directly:

> Henriksson Lab. *NGS 101: base-by-base documentation of NGS library chemistries.*
> GitHub repository, https://github.com/henriksson-lab/NGS_101 (accessed YYYY-MM-DD).

When reproducibility matters, include the Git commit or release used. Individual protocol
pages also link to the defining paper or commercial source, which should be cited for the
underlying method.

```bibtex
@misc{ngs101,
  author       = {{Henriksson Lab}},
  title        = {{NGS 101}: base-by-base documentation of {NGS} library chemistries},
  howpublished = {GitHub repository},
  url          = {https://github.com/henriksson-lab/NGS_101},
  note         = {Accessed YYYY-MM-DD}
}
```
