# Source retrieval

Run `python3 tools/get_sources.py --slugs stapleton-synthetic-long-reads__10.1371+journal.pone.0147229`, then the standard `tools/scrape_primers.py` on its external source directory.

Selected published originals: PMC4720449 main article, S13 Table (`pone.0147229.s030.docx`) and S1 Note (`pone.0147229.s017.docx`). Exact URLs/hashes are in the external `MANIFEST.tsv`. Other retrieved supplements remain unreviewed; the superseded bioRxiv original is excluded. Source files and text conversions remain outside the checkout.
