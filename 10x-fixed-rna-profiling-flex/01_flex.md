# 10x Fixed RNA Profiling (Flex) — research notes

## 1. What it is

This CG000674 variant measures fixed-cell RNA and antibody-tagged proteins in separate libraries. Gene-specific probe halves hybridize on RNA, then are ligated inside GEMs. An antibody-bound oligo is captured in the same GEM; both reporters receive GEM barcode and UMI by gel-bead primer extension.

## 3. Published oligo structure

🟢 The gel-bead primer is `5′-CTACACGACGCTCTTCCGATCT-N16-N12-TTGCTAGGACCG-3′`. Here `N16` is the GEM barcode and `N12` the UMI. The terminal `TTGCTAGGACCG` is printed, and should not be treated as an unknown transfer-oligo sequence.

🟢 The gene-expression library is printed with a 10-base i5 index, TruSeq Read 1 arm, GEM barcode, UMI, the bead-primer terminus, `BC8-NN-TACGTGCTAACCGCGT`, a ligated-probe insert, the Small RNA Read-2-side constant `TGGAATTCTCGGGTGCCAAGGAACTCCAGTCAC`, a 10-base i7 index and P7. `BC8` is a probe barcode window, not an extra GEM cell barcode. The full duplex appears on p. 85 of the guide; these exact constants are now surfaced on the schematic as key oligos.

🟢 The [official human v1.0.1 WTA CSV](https://cf.10xgenomics.com/supp/cell-exp/probeset/Chromium_Human_Transcriptome_Probe_Set_v1.0.1_GRCh38-2020-A.csv), compatible with NextGEM Flex v1, was read twice. Its header identifies GRCh38 2020-A and file format 2.0; all 54,580 rows have a 50-nt `probe_seq`, with 53,444 included in default analysis. The first TSPAN6 spliced target-region record is `GGTGACACCACAACAATGCAACGTATTTTGGATCTTGTCTACTGCATGGC`. The [10x format overview](https://www.10xgenomics.com/support/flex-gene-expression/documentation/steps/probe-sets/chromium-frp-probe-set-files) and custom design note identify this column as the combined target-region probe sequence without handles. The CSV does not itself assign the exact commercial physical LHS/RHS oligos, modifications or chosen specimen barcode mixture; that reconstruction remains blocked. 🟡 The RNA final library is assembled in the model from these p. 85 constants (P5–i5–TruSeq Read 1–N16–N12–`TTGCTAGGACCG`–BC8–NN–`TACGTGCTAACCGCGT`–50-nt insert–Read 2S arm–i7–P7). The guide names Small RNA Read 2 (Read 2S) but does not print the sequencing primer; the model's Read 2S and i7-read primer sites are derived from the printed constant `{{= flex.SMALL_RNA_READ2_ARM }}` (Read 2 primer = its reverse complement) and are labelled as derived.

🟢 The custom Flex design note specifies `5′-CCTTGGCACCCGAGAATTCCA-[25-nt target LHS]-3′` and `/5Phos/-[25-nt target RHS]-ACGCGGTTAGCACGTA-NN-ACTTTAGG-CGGTCCTAGCAA-3′` for singleplex BC001 (Table 7). Table 13 prints the complete example `EGFP-RHS-1` as `/5Phos/gccgtcctcgatgttgtggcggatcACGCGGTTAGCACGTANNACTTTAGGCGGTCCTAGCAA`. The note says the whole-transcriptome probe sets use four distinct physical barcode sequences per barcode ID, so the single custom BC001 string is not a substitute for the commercial barcode mixture.

🟢 CG000529 Rev C p. 4 prints the current protein capture oligo as `/5AmMC12/CGGAGATGTGTATAAGAGACAG-N10-N15-N9-CCCATATAAGAAA` for TotalSeq-C conjugates. `N15` is the antibody feature barcode, and the amino modifier attaches the oligo to the antibody. CG000674 Rev C step 1.1h adds a selected Antibody Multiplexing Barcode AB001–AB016 during hybridization; its GEM section says this oligo attaches to the antibody feature oligo inside GEMs. Appendix p. 85 prints a separate protein final library with GEM barcode/UMI, `AB8`, protein constants, feature barcode and a Nextera Read 2 arm. These segments now form a separate source-backed graph branch and completed protein construct; the drawn barcode windows remain unknown values. The physical AB oligo and its attachment geometry are still unresolved, shown as a validation warning. CG000477 Rev E instead uses TotalSeq-B and TruSeq Read 2, so its protein molecule was not inherited.

🟢 CG000674 Rev C Step 6 Sequencing Parameters (p. 73) recommend, for both libraries, {{= ', '.join(f'{k} {v}' for k, v in flex.READ_LENGTHS.items()) }} cycles (minimum Read 2 76); the model declares these acquired lengths.

🟡 The LHS/RHS hybridization drawing uses the CG000621 Rev D Table 7 custom architecture: LHS `{{= flex.LHS_CONSTANT }}`-[25-nt target], RHS 5′-phosphate-[25-nt target]-`{{= flex.RHS_CONSTANT }}`-NN-BC8-`{{= flex.CAPTURE_SEQUENCE }}`. The gel-bead terminus `TTGCTAGGACCG` is the reverse complement of that capture sequence. The commercial WTA physical oligos are not reconstructed.

## 4. Construct-changing steps

1. Label cells with antibody-oligo conjugates, then fix and permeabilize them.
2. Hybridize target-specific left and right RNA probe halves overnight; wash off unbound probes (CG000674 Rev C p. 15).
3. Add an Antibody Multiplexing Barcode oligo with the RNA probes; partition hybridized cells, bound antibody oligos, that AB oligo and barcoded gel beads into GEMs.
4. Inside GEMs, ligate the RNA probe pair; attach the AB oligo to the antibody feature oligo; extend the bead primer on both resulting reporters.
5. Break GEMs with Recovery Agent, pre-amplify both branches and clean up with SPRIselect; then Sample Index PCR (Dual Index Kit TS Set A) and SPRIselect make distinct gene-expression and protein-expression libraries (pp. 17–18). The model collapses pre-amplification and Sample Index PCR into one PCR step per branch because primer sequences are not printed.

## 5. Evidence boundary

🟢 The current and predecessor manuals establish GEM partitioning, nick sealing and barcode transfer; the current guide and labeling protocol establish the separate protein branch and its oligo pattern. The official v1.0.1 WTA CSV supplies commercial target-region sequences, and the custom note supplies verified physical custom-probe examples. The physical commercial probe inventory, actual barcode choices and AB oligo attachment geometry remain unresolved. 🟡 The gene-expression Read 2S/i7 primer sites are derived from the printed library constant rather than a printed primer; the protein shell follows CG000674 Rev C but uses placeholders for source-variable barcodes and indexes.
