# Reference manifest

Third-party source files are not committed. Retrieve them with:

```sh
python3 tools/get_sources.py --doi 10.1101/2025.06.19.660329
```

The public authorities are the latest bioRxiv paper version at DOI
`10.1101/2025.06.19.660329` and Pixelgen's current UM002 Proxiome Kit v2 manual linked
from <https://www.pixelgen.com/user-manual-v2/>.
