# Source retrieval

Run `python3 tools/get_sources.py --doi 10.1371/journal.pone.0010168`.
The published article and supplements are available through PMC2854151.
The external `splinkerette-pcr__10.1371+journal.pone.0010168/MANIFEST.tsv` records the exact
PMC Cloud original URLs, checksums and file identities. The inspected protocol
is published supplement `pone.0010168.s002.doc`, Protocol S1, not a later lab
website revision. Run `tools/doctext.py` and `tools/scrape_primers.py` there.
No third-party original or extracted text is checked into this repository.
