- [PacBio product note](https://www.pacb.com/literature/product-note-smrtbell-express-template-prep-2-0-for-large-insert-libraries/).
- Travers *et al.* 2010, doi:[10.1093/nar/gkq543](https://doi.org/10.1093/nar/gkq543), for SMRTbell topology.

Run `python3 tools/get_sources.py "PacBio SMRTbell Express Template Prep Kit 2.0"`.
