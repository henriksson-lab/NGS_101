# Sources

Fetch using the standard source tool:

```sh
python3 tools/get_sources.py --slugs libra-seq__10.1016+j.cell.2019.11.003
```

Originals and extracted text remain in the external source store. The main research note and catalogue/source_reviews/libra-seq__10.1016+j.cell.2019.11.003.json record source identity, inspected scope and deferrals. Superseded preprints are excluded from active chemistry.
